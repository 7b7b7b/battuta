# Battuta 1.0.0

- 键盘样本升级为四种自然变化的均衡轮换，连续输入不再机械地重复同一个声音。
- 四个变化共享原始 PCM，按键热路径只做内存索引，不增加可感知延迟，也不会让 DIY 音色占用四倍内存。
- 加载音色时保守清理素材前导静音，让 Topre、Keychron Red 等部分音色更跟手。
- 新增“一键更新并重启”：在应用内完成下载、Ed25519 验签、解压、替换与重启。
- 更新过程会显示下载与解压进度；失败后可以直接重试，并保留 GitHub 手动下载作为回退。

这是第一个包含应用内更新能力的版本，因此从 0.9.0 升级到 1.0.0 仍需手动安装一次；安装 1.0.0 后，后续版本即可一键更新。
