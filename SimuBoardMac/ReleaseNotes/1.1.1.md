# Battuta 1.1.1

- “历史”和“键盘”统计页继续做了渲染与数据流优化，切换、滚动和展开时的卡顿与瞬时占用明显下降。
- 历史页热力图现在支持悬停查看方块对应的日期或时段，以及该格记录的输入字符数；没有输入的方块也会显示 0。
- 键盘热力图与相关统计视图改为更轻的绘制路径，输入进行中打开统计页时不再把额外音频工作压在按键热路径上。
- 获授权的 BCP (Suit80) 现作为第 21 种内置键盘音色随 App、DMG 与 GitHub Release 发布，包含 28 段逐行、大小键与交替小键按下/回弹录音。
- 清理仓库中 0.1.0–1.0.0 的历史未公证 DMG；后续构建产物只通过 GitHub Release 分发，不再提交到源码树。
