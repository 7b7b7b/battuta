# Battuta 1.1.2

- 年度、星期 × 小时、应用时间线和键盘统计统一使用连续渐变色阶，并根据当前可见的非零数据自动调整范围；较多数据时使用 P95 抑制极端值，避免少数峰值让整张热力图失去层次。
- 对比热力图改为围绕 0 对称的连续色阶，使增加和减少拥有一致的视觉尺度。
- 历史页格子现在悬停后立即显示日期或时段与字符数；点击可固定详情，再次点击、点击空白处或按 Esc 可取消固定。
- 更新检查、下载清单和发布链接已迁移到 `wormforce/battuta`，后续版本继续通过新仓库提供应用内更新。
- 由于 1.1.1 只信任旧仓库的 Release 地址，从 1.1.1 升级到本版本需要手动下载 DMG 并覆盖安装一次。请勿先删除旧 App；1.1.2 继续使用相同 Bundle Identifier 和签名身份，以保留输入监控授权。
